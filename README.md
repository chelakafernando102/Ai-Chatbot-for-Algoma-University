# AlgomaU Virtual Assistant 🎓

An AI-powered university support chatbot developed for Algoma University students using Python, Flask, JavaScript, and Google Gemini AI.

The chatbot provides academic assistance, course registration guidance, prerequisite validation, and real-time conversational support through an interactive web interface.

---
## Live Demo
https://ai-chatbot-for-algoma-university.onrender.com


## ✨ Features

* AI-powered chatbot using Google Gemini API
* Course prerequisite & registration eligibility checker
* Smart FAQ system using fuzzy matching
* Real-time conversational responses
* Responsive modern UI
* Flask REST API backend
* JSON-based university knowledge base
* Hybrid AI + Search-first architecture

## 📚 Functionalities

### 🎯 Academic Assistance

Students can ask questions about:

* Programs & majors
* Tuition fees
* Scholarships
* Campus information
* Academic advising
* Residence options
* Course registration

### 🧠 AI Chat Support

If a question is not found in the knowledge base, the chatbot intelligently responds using Google Gemini AI.

### 📖 Course Eligibility Checker

The chatbot can:

* Detect course codes automatically
* Validate prerequisites
* Check failed/missing requirements
* Suggest alternative eligible courses

## ⚙️ Installation & Setup

### 1️⃣ Clone the Repository

```bash id="m3b8k2"
git clone https://github.com/your-username/algomau-chatbot.git
cd algomau-chatbot
```

### 2️⃣ Install Dependencies

```bash id="x4h1q8"
pip install -r requirements.txt
```

### 3️⃣ Configure Environment Variables

Create a `.env` file and add your Gemini API key:

```env id="n7v2l5"
GEMINI_API_KEY=your_api_key_here
```

### 4️⃣ Run the Application

```bash id="f5c9p1"
python app.py
```

Open your browser and go to:

```bash id="w2z8r4"
http://127.0.0.1:5000
```
